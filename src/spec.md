# Specification

## Summary
**Goal:** Increase the transparency (opacity) of the white box/background fill on specific, user-selected elements within the Services section to improve readability.

**Planned changes:**
- Update ONLY the 13 specified elements within the Services section service cards to use approximately 20% white background opacity (Tailwind equivalent `bg-white/20`), increasing from the current ~5%.
- Ensure no other elements (including any full-card gradient overlays), sections, or components are modified.

**User-visible outcome:** In the Services section, the selected card elements display a more visible white overlay (~20% opacity), improving text readability while leaving the rest of the page unchanged.

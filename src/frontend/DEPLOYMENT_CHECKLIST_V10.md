# Deployment Checklist - Version 10

## Pre-Deployment Verification
- [ ] Confirm Draft Version 10 is the intended version to promote to production
- [ ] Verify Draft Version 10 preview displays correctly in the staging environment
- [ ] Review all sections of the application in Draft Version 10:
  - [ ] Hero section with background image and CTAs
  - [ ] Services section with all six service cards
  - [ ] Coverage section with U.S. map visual
  - [ ] Contact section with form validation
  - [ ] Navigation and footer components
- [ ] Confirm all assets are loading correctly (images, fonts, icons)
- [ ] Test responsive design on mobile, tablet, and desktop viewports
- [ ] Verify light and dark mode themes render properly

## Deployment Steps
1. Navigate to the deployment dashboard
2. Select Draft Version 10 from the available drafts
3. Click "Publish" or "Promote to Production"
4. Confirm the deployment action when prompted
5. Wait for deployment process to complete
6. Note the deployment timestamp and version number

## Post-Deployment Validation
- [ ] Open the public live link in a fresh browser window (clear cache if needed)
- [ ] Verify the live site matches Draft Version 10 preview exactly
- [ ] Test all interactive elements:
  - [ ] Navigation menu (desktop and mobile)
  - [ ] Smooth scroll to sections
  - [ ] Contact form submission
  - [ ] All CTA buttons
- [ ] Verify all external links open correctly (caffeine.ai attribution link with UTM parameters)
- [ ] Test on multiple browsers (Chrome, Firefox, Safari, Edge)
- [ ] Test on mobile devices (iOS and Android)
- [ ] Confirm SEO metadata is present (title, description)
- [ ] Check browser console for any errors or warnings

## Rollback Plan
If issues are discovered after deployment:
1. Access deployment dashboard immediately
2. Revert to the previous stable version
3. Document the issue encountered
4. Address the issue in a new draft version before re-deploying

## Success Criteria
✅ Live production URL displays Version 10 content
✅ No console errors or broken functionality
✅ All assets load successfully
✅ Responsive design works across all devices
✅ Contact form validates and submits correctly
✅ Navigation and user interactions work smoothly
